# Credpay

Credpay is a **Universal Commerce API for autonomous agents**.

It gives AI agents a single interface to complete real-world purchases and commerce workflows across online stores, with payments and checkout orchestration built in.

## Why Credpay

AI agents can search, compare options, and make decisions on behalf of users. But they can't reliably complete online purchases like buying a product or booking a flight.

Today, every AI assistant hands users off at checkout.

Not because they lack intelligence, but because the internet's commerce systems were built for humans. Checkout flows, aggressive anti-bot protections, and fragmented payment systems make it difficult for agents to reliably complete transactions. So even today, users still have to step in and finish the job manually.

Credpay solves this.

We enable AI agents to complete transactions across the internet. Instead of trying to automate every website or building fragile integrations with thousands of merchants, agents send a transaction intent to Credpay, and we handle checkout, payment, and fulfillment.

## What Credpay Enables

- Buy products from store URLs through an API-first flow
- Create hosted checkout sessions for human-in-the-loop approvals
- Run direct autonomous checkout with agent-managed payments
- Track order lifecycle status from payment to completion
- Handle follow-up authorization when order totals change
